    General

    Identify drinks with AI

    Personal use only: your Anthropic API key is stored on this device and sent only to api.anthropic.com when you tap “Identify drink”. Usage is billed to your Anthropic account. Web search lets the AI look up ABV and origin of an identified product.

    Save to GitHub

    Uploads every change automatically and downloads changes from your other devices (on opening the app and every 2 minutes). Connect each device to the same repository. If a drink was edited on two devices, the newest edit wins. If the repository is public, anyone can see your drinks and photos – use a private one. Token: fine-grained, this repository only, “Contents: Read and write” (create). Stored only on this device.

    Backup

    Data is stored in this browser. Export regularly to keep a copy (photos included). Import replaces all current data.
